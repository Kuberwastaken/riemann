# `notes/` — annotated bibliographies

Six annotated bibliographies (~2000 lines total), one per approach family, each a
one-entry-per-item reading of the corresponding folder in [`../papers/`](../papers/):
citation, links, a summary of the contribution, its status, and an assessment of where
it sits in the attack on RH. These are the raw material the synthesis
([`../BREAKDOWN.md`](../BREAKDOWN.md)) and the deep dive ([`../ATTACK.md`](../ATTACK.md))
are built from — read a notes file when you want the item-by-item detail behind a claim
in those documents.

| File | Covers | Paired papers |
|---|---|---|
| [`spectral.md`](spectral.md) | Hilbert–Pólya and everything adjacent: pair correlation, `H=xp` and its regularizations, Connes' absorption realization, BBM 2017 + the full controversy, Sierra/Srednicki, random-matrix moments, Katz–Sarnak, Selberg analogy, experimental realizations | [`../papers/spectral/`](../papers/spectral/) |
| [`analytic-progress.md`](analytic-progress.md) | Unconditional progress by line of attack: critical-line proportion chain, zero-density incl. Guth–Maynard, zero-free regions, de Bruijn–Newman, Lindelöf, verification, Landau–Siegel | [`../papers/analytic-progress/`](../papers/analytic-progress/) |
| [`algebraic-geometric.md`](algebraic-geometric.md) | The Weil-transplant program: function fields, standard conjectures, F₁, the full Connes–Consani series, Deninger, and the Morishita convergence theorem | [`../papers/algebraic-geometric/`](../papers/algebraic-geometric/) |
| [`criteria.md`](criteria.md) | Every seriously-proposed equivalent criterion, plus the de Branges saga; organized by family with the "difficulty-conservation" verdict | [`../papers/criteria/`](../papers/criteria/) |
| [`surveys-expository.md`](surveys-expository.md) | Authoritative surveys, Riemann 1859, the famous failed proofs as primary sources, the Jensen-polynomials episode, blog/media coverage; includes folklore corrections caught along the way | [`../papers/surveys-expository/`](../papers/surveys-expository/) |
| [`recent.md`](recent.md) | The 2019–2026 frontier: Guth–Maynard aftermath, Connes–Consani 2023–2026, Landau–Siegel status, formalization, AI-assisted mathematics, verification records | [`../papers/recent/`](../papers/recent/) |

Paywalled classics that are not redistributable (Hardy 1914, Selberg 1942, Ingham 1940,
Weil 1952, Li 1997, and others) are recorded citation-only inside the relevant notes
file rather than as PDFs — see each file's header and [`../BREAKDOWN.md`](../BREAKDOWN.md) §7.
